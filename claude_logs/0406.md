## 第三步：A 类修复（policy 训练不足，需要重训）

> 前提：第一步确认 policy 不能转弯

**核心原因（三个叠加）**：
1. `ang_vel_cmd_levels` curriculum **缺失** → 50000 次迭代中 ang_vel_z 命令范围始终卡在 ±0.1 rad/s
2. `track_ang_vel_z` 奖励权重仅 0.5，线速度是 1.0，转弯优先级低
3. `joint_deviation_waists` 惩罚 -1.0，腰部旋转（转弯核心关节）被强烈压制

### A1：加入 ang_vel curriculum

**文件**：`source/unitree_rl_lab/unitree_rl_lab/tasks/locomotion/robots/g1/29dof/velocity_env_cfg.py`，约第 350 行

```python
@configclass
class CurriculumCfg:
    terrain_levels = CurrTerm(func=mdp.terrain_levels_vel)
    lin_vel_cmd_levels = CurrTerm(mdp.lin_vel_cmd_levels)
    # 新增：ang_vel curriculum（函数已存在于 mdp/curriculums.py）
    ang_vel_cmd_levels = CurrTerm(func=mdp.ang_vel_cmd_levels, params={"reward_term_name": "track_ang_vel_z"})
```

### A2：扩大 ang_vel 命令上限

同一文件，约第 173-175 行（`CommandsCfg`）：

```python
limit_ranges=mdp.UniformLevelVelocityCommandCfg.Ranges(
    lin_vel_x=(-0.5, 1.0), lin_vel_y=(-0.3, 0.3), ang_vel_z=(-0.4, 0.4)  # ±0.2 → ±0.4
),
```

### A3：平衡奖励权重 + 放宽腰部惩罚

同一文件，约第 247-287 行：

```python
# track_ang_vel_z weight: 0.5 → 1.0
track_ang_vel_z = RewTerm(
    func=mdp.track_ang_vel_z_exp, weight=1.0, ...
)

# joint_deviation_waists weight: -1.0 → -0.3
joint_deviation_waists = RewTerm(
    func=mdp.joint_deviation_l1, weight=-0.3, ...
)
```

### A4：重训后同步 deploy.yaml 命令范围

重训完成，导出新 policy.onnx 后，更新 deploy.yaml：

```yaml
# deploy/robots/g1_29dof/config/policy/velocity/v0/params/deploy.yaml
commands:
  base_velocity:
    ranges:
      ang_vel_z: [-1.0, 1.0]  # 与新训练范围一致
```
